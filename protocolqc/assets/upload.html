What happens when you press Review
  • Both PDFs are read on this machine and compared by 19 deterministic checks.
  • Every flag carries the exact text from both documents, with page and line.
  • Each quote is re-read from the source before anything is shown. If one does not match, the run is abandoned rather than published.
  • You get a review sheet to work through, and a JSON audit record with the file hashes.
  • Nothing is uploaded anywhere unless you tick an AI option, which sends the extracted document text to NVIDIA's API.
